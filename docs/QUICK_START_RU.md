# VASYA GNS LAB 1.1.0 — быстрый старт

## Linux (Pop!_OS 24.04 / Ubuntu 22.04+)
1. Скачайте из папки релиза **все** файлы `VASYA-GNS-LAB-1.1.0-Linux.tar.zst.partNNN`, файл
   `VASYA-GNS-LAB-1.1.0-Linux.tar.zst.parts.json` и `VASYA-GNS-LAB-1.1.0-Linux-Setup.sh` в одну папку
   (обычно «Загрузки»). Склеивать части вручную **не нужно**. Если Google Drive отдал ZIP-архивы — оставьте их как есть.
2. Запустите: `sh VASYA-GNS-LAB-1.1.0-Linux-Setup.sh` (или двойной щелчок → «Запустить»).
   Скрипт сам найдёт части, проверит sha256 каждой, распакует комплект и откроет мастер установки.
   Образов устройств в комплекте нет: установщик сам скачивает каждый образ с официального сайта и проверяет
   его SHA-256, Docker-образы скачиваются по закреплённому digest. Если образ получить не удалось, устройство
   помечается «образ недоступен», остальное устанавливается. Образы Cisco IOS не распространяются — как
   подключить свои лицензионные копии, описано в PRIVATE_IMAGES.md.
3. В мастере (8 шагов): Добро пожаловать → Проверка системы → Режим (рекомендуется «Полная лаборатория»)
   → Компоненты → Папка (по умолчанию `~/VASYA-GNS-LAB`) → Что изменится → Установка → Готово.
   До нажатия «Установить» ничего не меняется.
4. Откройте «Главная» → «Открыть лабораторию». Ярлык в меню приложений создаётся только по вашему согласию.

Без графики: `./install.sh --cli` (показывает план, спрашивает подтверждение).

sudo для режима «Полная лаборатория» не нужен. Системные изменения (пакеты apt, группы kvm/docker,
права uBridge) только **перечисляются** с точными командами и никогда не выполняются молча.

## Windows 10/11 (статус: НЕ ПРОВЕРЕНО на настоящей Windows)
1. Запустите `VASYA-GNS-LAB-1.1.0-Setup.exe` (права администратора не нужны, установка в
   `%LOCALAPPDATA%\VASYA-GNS-LAB`).
2. Образы устройств скачиваются автоматически во время установки (нужен Интернет), как и на Linux.
3. Для запуска устройств нужен GNS3 с GNS3 VM (Windows не запускает QEMU/Docker-устройства сама) — см. USER_GUIDE.

## Удаление
«Удаление» в меню слева (4 шага) или `vasya uninstall --level components|full`. Подробно — UNINSTALL_GUIDE.md.
