## Automatic downloads (end to end)

Run on 2026-10-29 with `vasya fetch` into an empty temporary `VASYA-GNS-LAB` folder, real network:

* uBridge 1.0.1 and VPCS 0.8.5 downloaded from the GNS3 PPA, checked against the lock, unpacked into
  `Runtime/bin`, both start and report their version.
* Images `core-linux-6.4-internet-0.1.img` (SourceForge), `empty8G.qcow2` (SourceForge) and
  `chr-7.1rc7.img` (MikroTik, zip, unpacked) downloaded; every stored file's SHA-256 equals its name.
* A private manifest without the image file: the Cisco device is reported as "image not available",
  exit code 0. With a local private folder holding the file: fetched and checked.
* `vasya fetch --dry-run` lists every missing image and whether it comes from the lock or a private source.

The URLs and hashes of all third-party files were checked on 2026-10-29; see
[RELEASE_SOURCES.md](RELEASE_SOURCES.md). One image URL (Ubuntu 20.04 cloud image, release 20210119.1)
could not be reached and is marked UNVERIFIED.

## Known gaps

* No run on a real Pop!_OS/Ubuntu desktop or on real Windows for this release (see the table above).
* KVM acceleration was not available on the build host; VM tests ran under TCG.
* Rootless Podman runtime tests run on the build host as unit tests only; Docker device runtime was
  checked earlier on Pop!_OS 24.04 with rootless Podman 4.9.3.
